# Everything said in Shift 2. A first draft: change anything you like.
# The format is explained at the top of Opening.txt.
# A conversation carries on past labels until it reaches "-> end", so every one needs an "-> end".
#
# The scene uses the labels briefing, vera, mitko, staff_door, locker_mine, seat, get_up, relay, back, get_up_depot,
# clock_out, phone, old_locker, camera and map, and each can have an _again for talking to it a second time.
# Walking into something locked uses staff_locked, cab_locked, street_closed and crossing.
#
# Each run uses its own labels for what's said on the way: _moving, _fast, _station and _short show one line while the
# player drives, then _stopped or _overran once the train comes to rest. The first run's labels start bolnichna_, the
# run to the signal's start drive_, and the run to the depot's start depot_.
