# Metropoliten

A first-person psychological horror game built in Unity.

A desperate man takes a job as a trainee metro driver in a poor, fictional Bulgarian-adjacent country whose metro shouldn't plausibly exist, and slowly realizes he wasn't hired by accident.

## Status

Early development. The Opening scene and Shift 1 are playable, from the main menu through the registry to the first drive, with music and sound throughout.

## Running it

1. Open the project in Unity 6000.6.7f1.
2. Open `Assets/Scenes/MainMenu.unity` and press Play.

| Action | Keys |
|---|---|
| Move | WASD |
| Look | Mouse |
| Sprint | Left Shift |
| Talk, continue | E |
| Choose a reply | W / S then E, or number keys |
| Drive the train | W for power, S for the brake |

## Working on it

- Each scene's dialogue is in `Assets/Dialogue`. `Opening.txt` explains the format.
- The Opening and Shift 1 scenes are generated by the scripts in `Assets/Editor`. **Metropoliten > Build Opening Scene** and **Build Shift 1 Scene** rebuild them and rebake the lighting, replacing any hand edits to the scene.
- All of the music and sound is generated too, by `Assets/Editor/Sound`. **Metropoliten > Forge Sounds** writes it to `Assets/Resources/Sound`. A line like `@ S_Cold` in a dialogue file plays one of those sounds at that point in the conversation.
