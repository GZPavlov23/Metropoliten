# Metropoliten

A first-person psychological horror game built in Unity.

A desperate man takes a job as a trainee metro driver in a poor, fictional Bulgarian-adjacent country whose metro shouldn't plausibly exist, and slowly realizes he wasn't hired by accident.

## Status

Early development. The Opening scene is playable from the main menu to the platform stairs. Shift 1 is still a placeholder, and there's no sound yet.

## Running it

1. Open the project in Unity 6000.6.7f1.
2. Open `Assets/Scenes/MainMenu.unity` and press Play.

| Action | Keys |
|---|---|
| Move | WASD |
| Look | Mouse |
| Sprint | Left Shift |
| Talk, continue | E |
| Choose a reply | W / S then E, or number keys |

## Working on it

- All of the Opening scene's dialogue is in `Assets/Dialogue/Opening.txt`. The file explains its own format.
- The scene is generated by the scripts in `Assets/Editor/OpeningScene`. **Metropoliten > Build Opening Scene** rebuilds it and rebakes the lighting, replacing any hand edits to the scene.
